### New Pangeo Notebook base image 2024.04.08
The default image for CIROH-2i2c image computing. Comes with built-in support for common hydrological libraries, along with integration with Hydroshare.

_The timestamp in the name refers to the version of the Pangeo Notebook base image that this image is built from._

- Branch: main [(pinned to a commit from February 12th, 2026)](https://github.com/CIROH-UA/awi-ciroh-image/tree/d86a62ae0b855c82991706bac2de19a313272b4b)
- Pull target: `quay.io/2i2c/awi-ciroh-image:d86a62ae0b85`

### Notebook with R and Python kernel
An image designed to be better-suited for R, including a fully-configured R environment and some useful hydrology libraries.

- Branch: [r-python](https://github.com/CIROH-UA/awi-ciroh-image/tree/r-python)
- Pull target: `quay.io/2i2c/awi-ciroh-image:f7f6aa41555b`

### NGIAB Data Preprocessor
An image containing dependencies of the NGIAB Data Preprocess software. Note that the *CIROH Community NextGen Hub* image provides a superset of these dependencies and may be preferable for more general use cases.

- Branch: [ngiab_datapreprocess](https://github.com/CIROH-UA/awi-ciroh-image/tree/ngiab_datapreprocess)
- Pull target: `quay.io/awiciroh/devcon25:ngiab_datapreprocess`

### CIROH Community NextGen Hub
A specialized image for using the NextGen framework. For more information on how to use this image, please see the [NextGen on 2i2c](https://hub.ciroh.org/docs/products/ngiab/distributions/nextgen-2i2c/) page on CIROH Hub.

To provide direct support for the NextGen framework, this image uses a unique environment configuration that can be fragile. If you are having issues with this image's Hydroshare integration, consider removing any user-installed libraries from `pip` and restarting your server.

- Branch: [ngen-2i2c](https://github.com/CIROH-UA/awi-ciroh-image/tree/ngen-2i2c)
- Pull target: `quay.io/awiciroh/ngiab-2i2c:v1.2.3`

### Community Assets Computation Hub

Contains dependencies for the [SYMFLUENCE](https://symfluence.org/) Earth-system modeling framework.

- Branch: [symfluence](https://github.com/CIROH-UA/awi-ciroh-image/tree/symfluence)
- Pull target: `quay.io/awiciroh/quay.io/awiciroh/symfluence:v1.0.0`
