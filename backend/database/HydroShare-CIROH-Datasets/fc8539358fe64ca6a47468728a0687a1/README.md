
## 🌊 Working with HydroShare, AORC data, HydroFabric and NextGen on CIROH JupyterHub Tutorial

This HydroShare resource provides a tutorial on the use of the Consortium of Universities for the Advancement of Hydrologic Science, Inc. (CUAHSI) HydroShare repository and linked CIROH JupyterHub computing platform on 2i2c in support of CIROH collaborative research and NextGen modeling. It introduces use of Jupyter Notebooks for retrieval of NOAA Analysis of Record for Calibration (AORC) datasets and setting up and executing NextGen for a small test watershed as a starting point for research with NextGen. 

---

### 📦 Contents

#### Files
- CIROH_HydroShare_Tutorial.docx. Tutorial instructions.
- NextGenVisualization.ipynb. Jupyter Notebook with code for visualizing NextGen files
- hydrofabric_visualization_utils.py. Code for visualizing the hydrofabric subset used by the notebook.
- forcings_visualization_utilis.py. Code for visualizing the NextGen forcings (inputs) used by the notebook.
- ngen_outputs_utils.py. Code for visualizing the NextGen outputs used by the notebook.

### 👥 Intended Audience

This workflow is ideal for:

- **Researchers** exploring watershed behavior or hydrologic modeling 
- **Practitioners** building custom model runs for operational scenarios 
- **Educators** teaching hydrologic modeling and reproducible workflows 

---

### 📘 Getting Started

To use this resource:

1. Download and printout if desired CIROH_HydroShare_Tutorial.docx.  Work through its instructions step by step. 
2. From HydroShare Open With **CIROH JupyterHub** to have the files transferred to JupyterHub.
