## Content of this resource:
* **readme.md**: This file explains the content of this HydroShare resource.
* **report-data**: The CSV file containing the USGS StreamStats reports data. It includes various streamflow statistics, basin characteristics, and hydrological data relevant to the stream gage at Chester C at Arctic Boulevard in Anchorage, AK. 
* **globalwatershed**: Shapefile of the delineated watershed upstream of the USGS stream gage.
* **globalwatershedpoint**: Shapefile of the USGS stream gage.
* **stage-vs-discharge**: Image of the USGS gage rating curve. 
* **basin_and_peakflow_report**: The PDF file of the basin charcteristics and peak flow statistics for the gage, created by StreamStats.
* **gage_information**: The PDF file of the USGS gage information, created by StreamStats. 
* **Disclaimer.txt**: USGS Data Disclaimer.
